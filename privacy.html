Privacy Policy

Effective date: September 16, 2026

Overview

Aegis Personal Automation (the "Application") is a private, personal-use application operated by its owner ("you" / "the user"). It is not a public service and is not made available to third parties.

Information We Access

The Application connects to your own Google accounts via the Google APIs (Gmail and Calendar). With your authorization, it may:

  • Read, organize, and file emails in your Gmail inbox.
  • Read calendar events to provide reminders and summaries.

How We Use Information

Accessed information is used solely to perform the Application's intended functions: email triage, daily digests, calendar reminders, and research tasks for the account owner. Data is processed on the owner's own systems and is not sold, shared, or transferred to any third party.

Data Storage and Security

No data is stored on any public server. Any local processing is performed on the owner's private infrastructure using standard access controls. OAuth tokens are stored locally and are not disclosed.

Google API Terms

The Application's use of Google API data adheres to Google's Limited Use requirements and the Google API Services User Data Policy.
